- Classic desktop: inherited and TT99 extended Orbit/file actions and rectangular selection; browser-tested.
- Files: list/grid/dual-pane rectangular selection and column ancestor context tested; current-column scrolling uses its own scroll surface.
- Tabletop: existing cards/piles/wall context actions preserved; **3D marquee not implemented or certified**.
- Dock/Taskbar: existing app jump menus preserved; not newly audited in every layout.
- Top/menu bars, launcher, widgets: existing direct controls remain; no universal semantic right-click layer is claimed.
- Native text, media, canvas and cross-origin documents: not replaced by a synthetic universal clipboard or OS menu.
